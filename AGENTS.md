# AGENTS.md

## Major events reporting

Standing rule (David / LineSpotting AB, 2026-10-22): every Grok Build CLI (`grok -p`) session and GBR job must report MAJOR events to [LinespottingOrg/grok-build-inbox](https://github.com/LinespottingOrg/grok-build-inbox), one comment or issue per event (comment on the app's existing inbox issue, else open a new one). Full rule: [rules/MAJOR-EVENTS.md](https://github.com/LinespottingOrg/grok-build-inbox/blob/main/rules/MAJOR-EVENTS.md).

Major events: App Review / Resolution Center replies posted; store submits/resubmits; binaries uploaded to ASC/TestFlight/Play; releases or rollouts; store record creation; IAP/subscription product changes; destructive or permanent actions. Include app, repo, action, exact text (replies) or summary, time (YYYY-MM-DD HH:MM Europe/Stockholm), machine, and a link. Never include secrets.
